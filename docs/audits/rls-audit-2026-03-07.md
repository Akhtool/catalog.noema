# Аудит RLS и доступа к данным

Дата: 2026-03-07

Источник проверки:

- Supabase MCP / Security Advisors
- чтение политик через `pg_policies`

## Итог

Проверка RLS выполнена. Основная проблема найдена в публичных политиках записи для anon/public.

## Критичная проблема

Для таблиц:

- `business`
- `category`
- `product`

были найдены публичные политики:

- `Allow public insert ...`
- `Allow public update ...`
- `Allow public delete ...`

Смысл проблемы:

- любой клиент с `anon` key мог писать в эти таблицы напрямую
- удаление маршрута `app/temp/slugs/page.tsx` убрало точку входа в приложении, но не устранило риск на уровне БД

## Что уже подготовлено в репозитории

Добавлены миграции:

- `supabase/migrations/20250307_remove_public_write_rls.sql`
- `supabase/migrations/ROLLBACK_20250307_remove_public_write_rls.sql`

Основная миграция удаляет 9 небезопасных политик записи для `public` на таблицах `business`, `category`, `product`.

## Что в порядке

- `profile`: доступ только у `authenticated`, со связкой на `auth.uid()`
- `business_user`, `brand`, `business_location`, `product_image`: публичного write-доступа не найдено
- публичный `SELECT` для каталога можно оставить:
  - `business`
  - `category` c фильтром `is_active = true`
  - `product` c фильтром `is_active = true`

## Что ещё осталось проверить вручную

### 1. Storage policies для bucket `business`

Через текущий MCP storage не проверялся.

Проверить в Supabase Dashboard:

- `Storage`
- bucket `business`
- `Policies`

Там не должно быть правил, которые позволяют `anon` или любому `authenticated` пользователю:

- загружать файлы в произвольные пути
- удалять чужие файлы
- писать вне своего `business_id`

### 2. Дополнительные рекомендации Security Advisors

- зафиксировать `search_path` у функций `update_updated_at_column` и `reorder_products`
- включить leaked password protection в Auth

## Важная оговорка

Локально в репозитории миграция уже есть, но это ещё не значит, что защита применена в проде.

Чтобы реально закрыть риск, миграцию нужно применить в самом Supabase-проекте.
