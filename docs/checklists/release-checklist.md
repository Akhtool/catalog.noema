# Release Checklist

Минимальный чеклист перед любым релизом или выкладкой в production.

Правило:

- любая серьёзная правка проходит через этот чеклист до релиза
- если `lint`, `typecheck` или `build` не проходят, изменение не выкатывается

## Обязательные проверки

1. Убедиться, что изменения ограничены текущей задачей и не затрагивают unrelated области.
2. Запустить `npm run lint`.
3. Запустить `npm run typecheck`.
4. Запустить `npm run build`.

## Проверка результата

1. Проверить основной пользовательский сценарий, который затрагивает изменение.
2. Если менялись доступы, RLS, Supabase policy или server actions:
   проверить публичный каталог и админский сценарий руками.
3. Если менялись миграции:
   подготовить rollback или понятный ручной откат.

## Перед выкладкой

1. Зафиксировать, какие файлы и сценарии реально изменились.
2. Отдельно выписать оставшиеся риски, если они есть.
3. Не выкатывать изменение, если `lint`, `typecheck` или `build` не проходят.
