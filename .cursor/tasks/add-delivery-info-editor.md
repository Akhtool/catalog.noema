# Реализация редактирования информации о доставке в настройках профиля

## Задача
Добавить возможность редактирования полей `deliveryRegions`, `cityDelivery` и `workingHours` в редакторе профиля бизнеса.

## Что было сделано

### 1. Frontend изменения

#### `components/business/business-profile-editor-sheet.tsx`
- ✅ Добавлена секция **"ОТОБРАЖЕНИЕ НА СТРАНИЦЕ"** во вкладку "О себе"
- ✅ Добавлены три поля с иконками:
  - **Регионы доставки** (`delivery_regions`) - с иконкой глобуса
  - **Условия доставки** (`city_delivery`) - с иконкой корзины
  - **Часы работы** (`working_hours`) - с иконкой часов
- ✅ Добавлен импорт иконки `Clock` из `lucide-react`
- ✅ Все поля имеют плейсхолдеры с примерами

### 2. Backend изменения

#### `app/admin/business/actions.ts`
- ✅ Добавлена обработка трёх новых полей в функции `updateBusiness`:
  - `delivery_regions`
  - `city_delivery`
  - `working_hours`
- ✅ Все значения нормализуются через `normalizeString()` (trim, null если пусто)

### 3. База данных

#### Миграции
- ✅ Создана миграция `add_working_hours_to_business.sql`
- ✅ Создан `migrations/README.md` с инструкциями по применению
- ℹ️ Поля `delivery_regions` и `city_delivery` уже существуют (миграция `add_delivery_fields_to_business.sql`)

## Инструкция по применению

### Шаг 1: Применить миграцию базы данных

**Через Supabase Dashboard:**
1. Откройте [Supabase Dashboard](https://supabase.com/dashboard)
2. Перейдите в **SQL Editor**
3. Скопируйте содержимое файла `migrations/add_working_hours_to_business.sql`
4. Вставьте в редактор и нажмите **Run**

**Или через Supabase CLI:**
```bash
supabase db execute -f migrations/add_working_hours_to_business.sql
```

### Шаг 2: Проверить работу

1. Откройте публичную страницу каталога (например, `http://localhost:3000/your-slug`)
2. Нажмите на кнопку редактирования профиля (если авторизованы как owner/admin)
3. Перейдите на вкладку **"О себе"**
4. Прокрутите вниз до секции **"ОТОБРАЖЕНИЕ НА СТРАНИЦЕ"**
5. Заполните поля:
   - Регионы доставки: `Грозный, Аргун`
   - Условия доставки: `По тарифу такси`
   - Часы работы: `Пн-Вс: с 10:00 до 22:00`
6. Нажмите **"Сохранить изменения"**
7. После сохранения страница обновится и данные отобразятся в информационном блоке под баннером

## Где отображаются данные

Поля отображаются на публичной странице каталога в белом блоке под баннером с логотипом:
